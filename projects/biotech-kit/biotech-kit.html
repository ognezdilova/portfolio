Project Overview

Biotech Kit (BK) is a local software platform for acquiring, visualizing, processing, and managing biosignals in real time. The project is designed as a modular research environment rather than a single-purpose application, providing a reusable foundation for future biotechnology projects such as EMG, EEG, ECG, and Brain-Computer Interface (BCI) systems.

The first implementation focuses on electromyography (EMG) data acquired from an ESP32-based hardware platform. The software architecture is planned to be hardware-independent, allowing new acquisition devices to be integrated with minimal changes to the rest of the system.

The application consists of a Python backend responsible for device communication and signal processing, and a modern web-based frontend running locally in the browser. This separation allows the backend to remain unchanged if the user interface is replaced in the future (e.g., with a Qt desktop application).

Project Objectives

  • connecting to biosignal acquisition hardware;
  • receiving real-time data streams;
  • visualizing signals live;
  • processing and filtering raw data;
  • recording experimental sessions;
  • replaying previously recorded data;
