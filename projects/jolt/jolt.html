Project Overview

JOLT is a forearm band that allows users with upper limb amputations or impairments to control a computer mouse using natural arm gestures. By strapping JOLT to the residual limb, users can move the cursor by tilting their arm, click with a joystick button, and toggle their range of motion and sensitivity.

How It Works

JOLT uses a gyroscope to detect the rotational velocity of the forearm in real time. These gyroscope readings are filtered and mapped to cursor movement, which is transmitted wirelessly to any computer via Bluetooth HID. The computer sees JOLT as a standard Bluetooth mouse, requiring no drivers or software installation.

Cursor Control

Tilt arm forward/back → The cursor moves up/down

Tilt arm left/right → The cursor moves left/right

The cursor continues moving as long as the arm is tilted, and stops when the arm returns to its neutral position.

Clicking

Single press of the joystick button → The cursor performs a left mouse click

The work is continued on implementing the EMG sensor for input control, shifting away from the button to muscle signals.

Freeze / Unfreeze

Toggle switch ON → The cursor freezes in place

Toggle switch OFF → The cursor unfreezes and resumes movement

Technical Details

  • Microcontroller: ESP32 (dual core, 240MHz)
  • Gesture sensing: MPU-6050 gyroscope
  • Signal filtering: Low-pass filter to smooth gyroscope noise
  • Wireless protocol: Bluetooth Low Energy HID
  • Cursor mapping: Gyro rate scaled and constrained to ±15 pixels per frame at 50Hz
  • Auto-calibration: IMU settles over first 50 loop iterations on boot before cursor activates
  • Companion web app: Real time device dashboard built in React and TypeScript, deployed on Vercel

Companion Web App

For now, JOLT includes a web-based dashboard accessible from any Chrome or Edge browser. The app connects to JOLT over Web Bluetooth and displays:

  • Device connection status
  • Power and baseline state
  • Live gyroscope values
  • Spatial movement visualization

Personal Impact

From the hardware perspective, I integrated a MyoWare 2.0 EMG sensor with an ESP32 microcontroller, designing the signal acquisition pipeline using Arduino IDE and calibrated the electrode setup to capture stable muscle activity signals.

From the software perspective, I used Arduino IDE to write a firmware to stream EMG data in real time and developed a Python pipeline to log and structure biosignal data for future neural network training.
